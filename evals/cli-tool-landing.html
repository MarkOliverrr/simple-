01 — features

01 / commits

organic growth

Every commit sprouts a leaf. Merges form cross-pollinating branches. Watch your code grow organically over time.

02 / taxonomy

author species

Different contributors represent different botanical species. Identify high-frequency contributors by flower density.

03 / renders

ascii or vector

Output directly as pure ASCII art inside your terminal, or export to standard SVG and vector assets for web publishing.

02 — installation

Install the package globally via your preferred package manager to run the CLI command anywhere on your machine.

npm i -g gitgrove
